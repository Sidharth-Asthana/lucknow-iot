SoftwareWhy

🚀 First-time setup

git clone https://github.com/Sidharth-Asthana/lucknow-iot.git
cd lucknow-iot
bash scripts/setup.sh
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
# → open http://localhost:8123 and complete HA wizard

cp -r ha_config/. volumes/ha_config/
docker compose restart homeassistant

Then paste dashboard/lovelace.yaml into HA → Settings → Dashboards → Edit → Raw Config Editor.

🌬 Cooling Modes

ModeTriggerAction
coolingRH < 65%, T > 26°CDampers open, fans run (speed ∝ ΔT)
monsoon_bypassIndoor RH > 65% for 3 minDampers closed, fans off, dehumidifier on
winter_bypassOutdoor T < 18°C for 30 minEverything off, passive solar mode
offManualAll actuators off

Fan speed formula: speed% = clamp((outdoor_T − inlet_T) / 14 × 100, 20, 100)
